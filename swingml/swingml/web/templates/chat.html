Ask the coach

Questions about your swings, answered by a language model on this computer from the {{ ok_count }} swing{{ '' if ok_count == 1 else 's' }} on record. It reads your measurements, not your videos, and it is told how precise each one is - so it should not make much of a difference smaller than a measurement's own error.

Set up the local coach

  1. Install Ollama from ollama.com and open it.
  2. In a terminal, run ollama pull gemma3:4b (about 3 GB, once).
  3. Come back here. Nothing else to configure.
